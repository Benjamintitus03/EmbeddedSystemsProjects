Eco Drone

Overview
Eco Drone is a quadcopter built using recycled plastic components and open source hardware.

Features
- obstacle avoidance
- telemetry logging
- modular sensor system
- recycled frame design

Hardware
- Arduino Nano
- ultrasonic sensor
- MPU6050 IMU
- brushless motors
- ESC controllers

Software
Arduino firmware handles flight control and sensor polling.
Python handles telemetry logging and command input.

Build Steps
1 assemble frame
2 mount motors
3 wire ESCs to Arduino
4 install sensors
5 flash firmware
6 run telemetry script
